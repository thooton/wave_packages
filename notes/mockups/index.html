Notes for the Sonim XP3

Apple Notes (iOS 17, light) laid out for a 240×320 screen, a d-pad, two soft keys and a T9 keypad. Drawn at 1 px = 1 dp; the app uses these sizes and colours. Refined from the first pass; what changed and why is listed under the screens.

Keys

Up / DownMove one row; on a note, the cursor. Up from a list's first row opens the search.
OKOpen the folder or note; in a note, a new line; on an empty folder, a new note.
KeypadOn a list, starts a search with that key; in a note, types (T9).
Menu (left soft key)The menu for where you are (on release).
Back (right soft key), LeftBack one page: note → folder → Folders → out. Left only on lists. A note is already saved; an empty one is thrown away.

What the refinement changed

  • Room for notes. The first pass spent 110 of 320 dp on chrome before the first note. The search field now hides until it is used (typing on a list, or Up from the top), so a folder shows four notes, not two and a half; the back row is 22 dp and the large title 22sp in 30 dp.
  • Focus you can see. iOS's grey pressed state (#D1D1D6) barely shows on the XP3's panel; the picked row is now a yellow wash (#FFE9A6) inset 3 dp in the card with 7 dp corners, as Notes highlights the selected note on iPad and Mac, and the hairlines either side of it give way.
  • Readable greys and yellow. iOS's #8A8A8E secondary text is too faint at 11.5sp on this screen; previews use #6E6E73. Notes' yellow stays #E0A500 for icons and the caret, and is deepened to #B88600 where it is text (Folders, Cancel, Save).
  • No decoy controls. The first pass carried Apple's checklist button in the note's toolbar, which the app would not have; the note is now the whole page, with no toolbar. The empty folder no longer says "No Notes" twice.
  • A menu that rises from the soft key. The menu now sits at the foot of the screen, full width, over the soft key that opens it, with Apple's thick rule between New Note and what acts on the note, and real line icons in place of characters.
  • Search says where. Search covers every folder, so each hit gets Apple's third line with its folder.
  • Missing pages added. Recently Deleted (with Recover), the folder picker for Move, New Folder and the Delete Folder alert, whose buttons use Notes' yellow rather than iOS blue.
  • Android's status bar. The XP3's own bar, on the page's grey with dark icons, rather than an iPhone's.
